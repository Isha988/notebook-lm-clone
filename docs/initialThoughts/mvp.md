## The main feature of Google's Notebook LM that I have seen in the original projects are as follow:
1. It supports different kinds sources for data feeding: example, file upload (pdf, images, docs, audio etc), youtube, playbook, drive, textbook, copied text.
2. It also supports web search, which also give option to add results in the sources.
3. Chat interface of the Notebook LM, it the main part of the product left side shows the sources attached, mid section have the chat history and chatbox to send message and a right panel.
4. Right Panel of the Notebook screen called studio is an interesting piece, it gives options like create audio overview in different languages, video overview, mind maps, flash cards, slide deck, report, infographic, quiz. Seems like showing the data in different formats.
5. Multiple Notebook creation support, a user can make multiple notebooks.
6. Collections supports, user can make collections and can arrange notebooks in collections.
7. Notebook share feature with both viewer and editor access.
8. There are more small features, like chat management (chat configuration and deleting history on the notebook screen), search and o/p language, way of listing notebook etc on the home screen etc.

## Features I want in MVP:
1. User Management: Google Login with proper authentication and authorization.
2. Notebook List: It should have proper CRUD features on Notebooks.
3. Data Sources: Minimum I wanna PDF but gradually I wanna support all the different as much as possible.
4. Chat Interface: The main feature of the project, which is a RAG based chat interface.
5. CRUD on data sources: Data sources should have CRUD support and a feature to select or deselect particular source for chatting.
6. Hosting: Should be hosted on some valid domain on Hostinger or AWS, most likely I will go with Hoistinger because it support prepaid VPS hosting, no risk of extra bills and cost management handling.
7. Option for the users to add their own api key and config, so that I can save on my AI credit whenever I show my project to someone.
